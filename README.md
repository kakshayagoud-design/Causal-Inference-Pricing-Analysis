# Causal-Inference-Pricing-Analysis
A data analytics project to study the impact of dynamic pricing changes on revenue using causal inference and synthetic control methods.
## Project Objectives

- Analyze historical transaction data.
- Study the relationship between pricing and revenue.
- Understand the impact of dynamic pricing changes.
- Compare actual revenue with estimated counterfactual revenue.
- Present findings using visualizations.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- DoWhy
- EconML
- Streamlit
