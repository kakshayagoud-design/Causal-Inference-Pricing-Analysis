# Causal-Inference-Pricing-Analysis
A data analytics project to study the impact of dynamic pricing changes on revenue using causal inference and synthetic control methods.
## Project Objectives

- Analyze historical transaction data.
- Study the relationship between pricing and revenue.
- Understand the impact of dynamic pricing changes.
- Compare actual revenue with estimated counterfactual revenue.
- Present findings using visualizations.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- DoWhy
- EconML
- Streamlit

Day 1: Created the repository and documented the project overview.

## Problem Statement

Traditional A/B testing can be difficult in interconnected marketplaces because pricing changes may affect multiple markets.

This project aims to estimate the impact of dynamic pricing changes on revenue using causal inference and synthetic control methods.

## Expected Outcomes

- Estimate the impact of pricing changes on revenue.
- Compare actual revenue with estimated counterfactual revenue.

## Day 3: Dataset Planning

### Objective
To plan the dataset required to analyze the impact of dynamic pricing changes on sales and revenue.

### Planned Dataset Columns
- Date
- Product
- Category
- Price
- Units_Sold
- Revenue
- Price_Change
- Treatment_Group
- Control_Group

### Treatment and Control Groups
The treatment group contains products whose prices are changed. The control group contains comparable products whose prices remain unchanged during the study period.

### Planned Analysis
1. Analyze sales and revenue before and after pricing changes.
2. Compare treatment and control groups.
3. Investigate the relationship between price changes and revenue.
4. Prepare the data for causal impact estimation.
